# AI-103 QUEST

日本語の資格学習 RPG。Node.js 24 と組み込み SQLite を使った、単一利用者向け Web アプリです。外部 API キー、外部 DB、npm の実行時依存パッケージは不要です。

## 起動

```sh
cd /workspace/codex
npm ci --ignore-scripts
npm test
npm start
```

標準ポートは `3000`。`PORT`・`HOST`・`QUEST_DB` で変更できます。開発時は `npm run dev` でサーバーを再起動します。フロントエンドはビルド不要です。

## 使い方

- 「冒険の拠点」から通常戦を始め、選択肢を選んで回答を確定します。
- ヒントは MP を 1 消費し、その問題を支援ありとして記録します。Lv.2で「見破り」、Lv.3で「ヒール」も使えます。
- 「クエスト」で分野・問題数・モードを指定できます。ボスは実時間 5 分、ヒントなしです。
- 空回答は回答数に含まれますが、HP・習熟度・経験値を変更しません。
- 宿屋への帰還は通常戦を終了して HP・MP を回復します。単なる再読み込みやタブ閉鎖では冒険を終了しません。
- 「知識の図鑑」で学習状態を確認し、各問題の「記録なしで解く・解説を見る」から自由に演習できます。図鑑内の回答は経験値・回答履歴・正答率・習熟度・HP/MPを変えません。
- 「冒険の記録」では、通常戦・ボス・診断で保存した結果と解説を確認できます。
- 「学習範囲・出典」で学習テーマ、問題数、公式資料と試験範囲の確認状況を確認できます。
- 「設定・データ」で問題パックを読み込み、バックアップの保存・復元、監査ログの保存ができます。

初期データは **通常戦だけで150問**、全モード合計174問です。分野ボス12問・最終ボス6問・診断6問は別枠です。問題文をモード間で複製していません。

Microsoft Learnの [AI-103公式試験ガイド](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-103) を2026-10-26に取得し、2026-04-16版の評価スキル64項目と各問題を対応付けました。領域別の通常戦は以下のとおりです。

|領域|公式比率|通常戦|
|---|---|---:|
|計画・管理|25〜30%|42問|
|生成AI・エージェント|30〜35%|48問|
|画像・動画|10〜15%|20問|
|テキスト・音声|10〜15%|20問|
|情報抽出・検索|10〜15%|20問|

**「クエスト」→「セット1・50問で開始」** などのボタンで、重複しない50問×3セットを選べます。セットごとの領域比率も公式範囲内です。分野や問題数を指定した短い演習もできます。

50問セットは学習用の構成です。通常戦のHPルールを適用するため、HP0で途中終了します。本番の固定問題数・時間・採点方式や合格率を再現・保証するものではありません。公式ページでは試験時間120分を確認しましたが、アプリの通常戦は時間制限なし、ボスは従来の5分です。

全選択肢の理由、判断ポイント、公式資料へのリンクと確認日を表示します。「学習範囲・出典」で通常戦150問、別枠24問、公式の比率、64項目の対応状況を確認できます。[詳細な対応表](docs/exam-coverage.md) と [調査結果](docs/content-review.md) も参照してください。

問題は独自作成であり、実際の試験問題やMicrosoftの知識チェックを転載していません。項目に関連する設問を配置していますが、各項目内の全API・全機能を網羅する保証ではありません。難易度は教材内の目安です。

## 旧版から更新する場合

1. 先に「設定・データ」でバックアップを書き出し、アプリを停止します（起動中のターミナルで Ctrl+C）。
2. 最新コードを取得します。ZIPの場合は展開した最新版へ、旧フォルダーの `data/` をフォルダーごとコピーします。`data/backup.key` も同じまま保持し、公開しないでください。
3. 最新版のフォルダーで `npm ci` → `npm start` を実行します。WindowsのPowerShellでは `npm.cmd ci` → `npm.cmd start` も使えます。
4. 旧画面が残る場合はアプリのタブをすべて閉じて開き直してください。ブラウザーの学習データ消去は不要です。
5. 旧教材（SAMPLE-1・48問版・以前の150問版）を使っている場合、冒険を終えてから「設定・データ」または拠点の **「新しい教材に切り替える」** を押します。

既存のセッション・問題アーカイブ・回答履歴・経験値は保持します。進行中の冒険は旧問題のまま継続し、終了後に明示的に教材を切り替えます。今回の選択肢改訂は意味変更revisionです。改訂問題の最初の有効な通常戦回答でその問題の習熟度を `unseen` へ戻し、新しいrevisionの学習を始めます。図鑑での演習ではこの更新も発生しません。旧問題の履歴には当時の選択肢・解説が表示されます。

## レベルアップと呪文

100 EXPごとにレベルが上がり、「Lv.xに上がった！」と、能力の変更前後・増加量・新しく覚えた呪文を表示します。毎レベル最大HP＋1、偶数レベルで最大MP＋1です。通常戦中に上がった場合は増加量だけ現在HP/MPも増えますが、全回復はせず、回答でHP0になった場合の敗北は取り消しません。ボスのHP設定は従来どおりです。

|習得|呪文|MP|効果|
|---|---|---:|---|
|Lv.1|ヒント|1|判断のポイントを表示|
|Lv.2|見破り|1|不正解の選択肢を1つ除外|
|Lv.3|ヒール|2|HPを2回復（最大まで）|

通常戦でのみ使え、各呪文は1問につき1回です。HPが満タンのヒールは拒否し、MPは消費しません。いずれかの呪文を使った問題は支援ありとして採点します。再読み込み後も使用履歴とMPを保持します。既存ユーザーは現在レベルまでの呪文を使え、新しく開始する通常戦の上限には成長表を適用します。旧固定HP/MPで進行中だった通常戦は、次のレベルアップ時に成長表へ合わせ、表示も実際の増加量を使います。

## 選択肢強化版

`LEARN-PRACTICE-150-2026-10-28-2` は、全174問で各問2つ、合計348個の誤答候補とその理由を改訂しています。正答に近い条件の違い、認証と認可、承認と実行、検索と生成、形式と事実性などの混同を中心にしています。正答ID、公式項目の対応、50問セットへの所属は維持します。新旧の違いは `content/distractors.js` と [変更記録](docs/enhancements.md) に記載しています。

## 保存

`data/quest.sqlite` に学習状態・固定された問題パック・問題 revision・Attempt・Progress・EndState・冪等性記録・監査ログを保存します。サーバーを再起動しても継続できます。ブラウザーのローカルストレージには業務データを保存しません。

`data/backup.key` は、この環境のバックアップを認証する HMAC-SHA256 鍵です。値を公開・コミットしないでください。バックアップ JSON は暗号化されていません。別のマシンへ移す場合は SQLite を停止した状態で `data/` 全体を安全に移し、同じ鍵を保持してください。環境スナップショットには data/ を含め、アプリのプロセスは起動し直します。

この初期版にログイン・利用者分離はありません。同じサーバーへ接続するブラウザーは同じ学習データを操作します。認証のないインターネット公開には対応していません。

## 問題パック

JSON の形式：

```json
{
  "version": "MY-PACK-1",
  "schema_version": 1,
  "app_version": 1,
  "questions": [{
    "id": "P-001",
    "revision": 1,
    "change_type": "initial",
    "pool": "practice",
    "domain": "AI の基本",
    "type": "single",
    "text": "教師あり学習で通常必要なものは？",
    "choices": [{"id": "A", "text": "正解ラベル"}, {"id": "B", "text": "ラベルのない入力のみ"}],
    "correct": ["A"],
    "explanation": "入力と正解の対応を学習します。",
    "hint": "正解を教える方式です。"
  }]
}
```

- `pool`: `practice` / `domain_boss` / `final_boss` / `diagnostic`。
- `type`: `single` / `multiple`。複数選択は正答集合との完全一致で完全正答です。
- 問題 ID はパック内で一意。revision は正の整数。選択肢 ID、正答、パック互換性を検証します。
- 同じ version は上書きできません。既存 ID の変更は revision を上げ、`change_type` を `typographic`（表記修正）または `semantic`（意味変更）にします。
- 進行中のセッションがある場合、パック切り替えを拒否します。旧パックはアーカイブとして DB に残ります。
- 初期版では意味変更後の最初の通常戦の有効 Attempt で `unseen` に戻します。表記修正では既存の習熟度を保持します。

JSONでは `objective`（学習項目）、`difficulty`（`intermediate` / `advanced`）、`takeaway`（判断のポイント）、`choice_explanations`（選択肢IDごとの理由）、`sources`（参照資料配列）も指定できます。`choice_explanations` を指定する場合は全選択肢の理由が必要です。sources の各要素に `title` とHTTPSの `url` を指定し、必要に応じて `source_url`（確認した原文）、`publisher`、`checked_at` を記録します。引用元は設問の転載元ではなく、独自問題の根拠資料として扱います。旧形式のJSON・CSVは引き続き読み込めますが、選択肢別の解説や出典がない場合はその旨が表示されます。

CSV の列順（UTF-8、ヘッダー必須）：

```csv
id,revision,pool,domain,type,text,choices,correct,explanation,hint,change_type
```

`choices` と `correct` は JSON を CSV セルとして引用します。ダブルクォートは `""` としてエスケープ。セル内のカンマ・改行・日本語を扱えます。CSV の場合、画面で新しいパック version も入力してください。
