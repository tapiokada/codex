# 実装の判断と仕様 v1.3 の対応

提供された `AI-103_RPG_spec_v1.md` の状態遷移表を基準に実装。ユーザーの「初期版として進める」という回答に従い、未提供の既存仕様は以下の暫定定義で補っています。仕様書そのものは変更していません。

## 暫定定義

`config.js` に集約：通常戦 HP5/MP3、ボス HP3/300秒、ボス合格80%以上。経験値は自力完全正答10、支援完全正答5、誤答・一部正解2、空回答0。レベルは `1 + floor(EXP / 100)`。自力連続正答の復習間隔は1/3/7/14/30日。診断はHP減少なしで全回答後に完了（内部 `won`）。通常戦はHPを残して全問を回答確定すれば `won`。

支援あり完全正答は連続正答数・復習予定日を変えず、未学習の場合のみ `assisted_mastery_pending` にします。誤答後の過去の復習予定日は保持しますが、表示状態は `weak` を優先します。

問題数・対象分野・パックは開始時に固定します。サンプルの正答位置は教材として固定です。出題順はランダムで、セッション内の同一問題は重複しません。

## 状態遷移と保存

|仕様|実装|
|---|---|
|ST-01/02|開始設定を保存し、出題数0で開始。UIが別の出題コマンドを送る|
|ST-03|出題番号・問題ID・revision・出題時刻を保存。同じ出題の再送は件数を増やさない|
|ST-04/05/06|サーバーで採点。Attempt・HP・Progress・EXP・終了状態を同時コミット。空回答に回答時刻・回答時間なし|
|ST-07|サーバーUTCで期限を判定。期限超過で時間切れ。未回答Attemptを作成しない|
|ST-08/09/10|終了理由を固定。宿屋のみ通常戦HP/MP回復。終了後は業務変更を拒否|
|ST-11|現在問題のヒント使用をサーバー保存。支援付き回答の自力判定を防止。ボスでは拒否|
|ST-12|全問題・CSV・revision・互換性を検証後に新パックを切り替え。旧パックを保持|
|ST-13|HMAC-SHA256署名とschema・アーカイブ・集計を検証して原子的に復元|
|ST-14|SQLite `BEGIN IMMEDIATE` によりDB全体で書き込みを直列化。小規模単一ユーザー向けの、行ロックより広いロック|
|ST-15/16|scope・session・command_idで一意化、リクエストハッシュとレスポンスを保存。再送は元のレスポンスを返す|
|ST-17|クライアント時刻・自己申告の回答時刻を期限の証拠として使わない。受信時のサーバー時刻のみで判定|
|ST-18|成功監査も同一トランザクション。失敗時に全業務更新をロールバックし別トランザクションで失敗を監査。失敗は安全に再試行可能|
|ST-19|固定パックの問題ID/revisionを回答時に照合し、Attemptに evaluated_revision を保存|
|ST-20|保存済みAttempt・出題から集計し、終了時にEndStateへ保存。分母0はnull|

状態はSQLiteのJSON行に保持します。命令の一意制約と監査は専用テーブルです。すべての変更は `Engine.command()` 経由で、UIの表示やフォーカス移動は保存操作を起こしません。出題時には明示的なST-03を実行します。

通常戦・ボスの回答は期限ちょうどを受理し、1ms後を拒否します。期限を過ぎて受信した回答に対し、初期版は外部署名の時刻証明を受け付けません。クライアント時計変更による個別監査イベント・外部時刻証明・診断専用開始遷移は未実装です。サーバー時計が信頼できることが前提です。

## オフライン・更新

Service Worker は画面資産のみをキャッシュします。API・回答コマンド・学習データをキャッシュしたりオフライン再送したりしません。学習にはサーバー接続が必要です。オフライン完全学習は初期版の対象外。新Service Workerを冒険中に強制有効化しません。アプリ互換性はmanifestの `app_version: 1` で検証します。

## 復元と運用

バックアップに状態・全問題アーカイブ・元コマンド記録を含め、ローカル鍵で署名します。復元成功後は保存時の命令記録へ戻します。監査は追記専用で、復元しても消しません。同じ環境の鍵を保持したバックアップのみ受理します。鍵配布・移行用の外部署名方式は未定義です。

単一利用者・単一Nodeプロセス向けです。認証、複数ユーザー、試験日計算、学習日のタイムゾーン定義、既存データの移行、公式教材は追加仕様が必要です。日時保存はUTC、表示はブラウザーのタイムゾーンです。初期schemaは1で、異なるschemaの取込を拒否します。

全受入条件の網羅を主張するものではありません。自動テストの実行件数と、ブラウザーで確認した範囲を完了時に報告します。

## 教材更新（v1.1・48問版、2026-10-26）

v1.1では新規DBに48問の実務シナリオパックを導入しました。現行の問題数は以下の通常戦150問版を参照してください。既存DBのパックや履歴は変更せず、ユーザーの明示的なパック切替をST-12として実行します。進行中は切替を拒否します。既存CSV列と基本schemaは1のまま維持し、追加の解説・出典フィールドは省略可能です。原文参照は固定コミットとSHA-256で記録します。回答前レスポンスから正答・解説・選択肢別理由・判断ポイントを除外し、受理された回答と履歴で返します。詳細は content-review.md を参照してください。

## 通常戦150問版

公式ガイドを取得して5領域・64項目への対応情報を追加しました。通常戦150問と別枠24問を区別します。`practice_set` は通常戦でのみ指定できる1/2/3で、開始時に問題フィルターと予定数を確定してセッションへ保存します。各セット50問、同一戦内およびセット間で重複しません。通常戦のHP終了規則は維持します。既存の問題はIDを維持して分類メタデータの更新を表記修正revision2として保存し、旧パックをアーカイブに残します。

## v1.3 図鑑演習・選択肢強化・成長

図鑑演習はDBへ書かない読み取り専用経路を使用します。通常戦の成長表と3種類の呪文を `progression.js` に定義し、回答・支援と同じトランザクションで更新します。レベルアップでHP0の敗北は取り消しません。全174問で2つずつの誤答候補と説明を改訂し、意味変更revisionとして旧パックを保持します。詳細は [enhancements.md](enhancements.md) を参照してください。
