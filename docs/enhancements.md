# 図鑑演習・選択肢・成長演出（v1.3）

## 図鑑の記録なし演習

図鑑の通常戦問題を選んで単一・複数選択に回答し、正答、全選択肢の理由、参照資料を確認できる。再挑戦と図鑑へ戻る操作も提供する。

`GET /api/collection/question` と `POST /api/collection/answer` は読み取り専用。通常戦の `Engine.command()` を使わず、セッション、Attempt、Progress、経験値、冪等性記録、監査ログを作成・変更しない。HP/MPも不変。採点の検証・集合比較は通常戦と同じ関数を使う。回答前は公開項目を限定し、正答・解説・誤答候補の編集メタデータを返さない。

問題はパックとrevisionに固定する。切替後も旧パックが保持されていれば、表示していた旧問題をその版で答え合わせできる。ボス専用問題は図鑑の経路から取得しない。演習の選択・結果はブラウザーのメモリーだけにあり、再読み込みで消える。進行中のボスの実時間は通常どおり進むが、図鑑演習がその成績を変更するわけではない。

## 誤答候補

174問すべてに手動編集の誤答候補を2つずつ追加・置換し、各理由を更新。残りの候補と正答のうち、妥当な既存内容は保持した。自動的に他問の正答を無検証で混入する方式は採用していない。

主な混同：

- 認証の成功と対象操作の認可、開発者IDと実行ID
- プロジェクト管理APIとモデル推論API
- 受付・承認と実行完了、事前承認と事後監査
- 根拠の取得と生成での利用、relevanceとgroundedness
- JSON構文・スキーマ・業務上の事実性
- 信頼度の高さと原文・業務ルールによる検証
- 音声認識・翻訳・音声合成、画像生成・画像理解

別条件なら有用な方法でも、今回の前提を満たさない理由を説明する。特にキー認証とID認証の両案が成立し得た `LEARN-01-02` は、キーを発行・保管せず実行IDを使う条件を明示した。実際の本試験問題を転載したものではなく、本試験と同じ難易度を実測したという主張もしない。

問題文・正答ID・選択肢ID・出典の対応を原則保持しつつ、全問のrevisionを上げ `semantic` とする。意味変更の既存ルールにより、新版で初めて有効な通常戦回答をした問題は習熟度を `unseen` へ戻す。旧Attemptの選択肢や解説は旧パックを参照し続ける。経験値とレベルはパック切替で減らない。

## レベルと呪文

ユーザーが承認した成長表：最大HPは `5 + level - 1`、最大MPは `3 + floor(level / 2)`。既存レベルからも導出できるため、保存schema versionは1のまま維持する。

通常戦の経験値・レベル更新と同じトランザクションで最大HP/MPを更新する。現在値は上限の増分だけ回復し、HP0による敗北は維持する。旧冒険の固定上限が残っている場合は次のレベルアップ時に成長表へ合わせ、レスポンスには実際の上限の変更を記録する。

レスポンスの `level_up` に変更前後のレベル・最大HP/MP・習得呪文を含める。冪等性レスポンスにも保存し、再送で能力を二重更新しない。成功監査の失敗時も能力とレベルをロールバックする。UIは取引IDごとに一度だけdialogを表示し、再読み込みで過去の演出を再生しない。新しい呪文がないレベルではその旨を表示する。複数レベルの上昇も変更前後と該当する全習得呪文を返せる。

- ヒント：Lv.1、MP1、判断ポイント。
- 見破り：Lv.2、MP1、不正解候補1つだけを除外。正答は除かない。
- ヒール：Lv.3、MP2、HP2回復、最大値まで。

通常戦のみ、各問・各種1回。未習得、MP不足、重複、満タン時ヒール、ボス・診断での支援を拒否する。旧形式のヒント使用履歴も維持し、新形式へ追加しても支援なし扱いへ戻さない。ヒールも使用問題を支援ありにする。

## 検証

採点・全174問の改訂差分、図鑑APIの全業務状態・監査・冪等性記録の不変、レベル境界、実際の能力増加、呪文の条件と消費、再送・ロールバック・旧ヒント履歴を自動テストで検証する。ブラウザーでは図鑑の誤答・正答・複数選択、Lv.2/Lv.3表示、見破りとヒール、再読み込み、スマートフォン表示を確認する。
